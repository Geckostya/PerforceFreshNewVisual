# P4FNV 0.1.4

## Highlights

- Restore the main window size, position, and maximized state after a normal exit, while ignoring a saved position that is no longer on an available monitor.
- Refine the workspace sidebar controls to keep its compact and expanded states clear at all window sizes.
- Refresh the P4FNV application icon across the Windows portable release assets.

## Release integrity

The GitHub Release includes SHA-256 checksums, detached Ed25519 signatures for the archive and update metadata, and SLSA provenance tied to the repository and exact release tag.
