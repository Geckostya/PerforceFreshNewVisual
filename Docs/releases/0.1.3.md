# P4FNV 0.1.3

The first Windows x64 portable release candidate of P4FNV. Earlier tagged validation attempts stopped safely before packaging and did not create a release.

## Highlights

- Connect to Helix Core and work with workspaces, files, changelists, shelves, streams, jobs, labels, history, and resolve workflows from a focused desktop UI.
- Review risky operations before applying them and keep long-running work visible through structured progress and recovery states.
- Download a portable ZIP without an installer or administrator access.
- Check for signed updates in the application, review release notes, and install only after explicit confirmation.
- Preserve application settings, connection profiles, caches, and unmanaged files during portable updates.

## Release integrity

The GitHub Release includes SHA-256 checksums, detached Ed25519 signatures for the archive and update metadata, and SLSA provenance tied to the repository and exact release tag.

## Release pipeline

- Make Windows path assertions independent of short-path aliases on hosted runners.
- Keep workspace-scan command tests self-contained instead of depending on a machine-wide `p4.exe` installation.
